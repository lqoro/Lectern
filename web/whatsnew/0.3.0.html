What's new in Lectern 0.3.0

  • A faster default model. On Apple Silicon Macs, the recommended Balanced model now uses the Neural Engine. On an M4 it transcribed about 1.7× faster than the model most of you have been using (large-v3-turbo q5), with the same accuracy: its words matched the full-size reference 99.5% of the time, against 99.3% for the old one. It is a bigger download (about 1.6 GB, because it includes the Neural Engine part).
  • Fastest (Parakeet) — beta. A new optional model for Apple Silicon Macs on macOS 14 or newer. On an M4, two real livestream recordings (112 and 326 minutes) ran about 16–18× faster than the old model, and about 10× faster than the new default. The 112-minute one took 19 seconds instead of 5 minutes 23. Accuracy is similar for English (95–97% of words match; most of the difference was foreign-language stretches where the old model made things up). It is a beta, so it is never picked for you: choose it in Settings if you want it. About 555 MB.
  • Your current model keeps working. Lectern shows a banner offering the new default. Until it finishes downloading nothing changes, and you can say “Not now”.
  • Intel Macs and macOS 12–13 keep using the Whisper models exactly as before.
  • Speeds are measured on an M4 Mac. Other chips will differ; M1 and M1 Pro numbers will follow.
