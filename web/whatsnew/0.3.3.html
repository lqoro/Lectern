What's new in Lectern 0.3.3

  • Record this Mac's sound. In New recording, choose This Mac's sound to record a YouTube lecture, a Zoom class or anything else your Mac plays, straight from the system instead of through the microphone. It doesn't need the speakers, so headphones are fine. Needs macOS 13 or newer.
  • The first time, macOS asks for Screen & System Audio Recording permission. Lectern records the sound only, never the picture. Allow it, then reopen Lectern.
  • Everything the Mac plays is recorded, notification sounds included, so close what you don't want in the lecture.
  • Set the default in Settings › Record from. The quick-record shortcut uses it too, so switch it back to Microphone before a class in the room.
