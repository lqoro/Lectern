What's new in Lectern 0.3.1

  • Fixed: still seeing the old model list after updating. After an update Lectern could keep talking to the previous version still running in the background, so the new models never showed up. It now waits for the old one to close, and only carries on once the new one is running.
  • Parakeet is always listed on Apple Silicon. On a Mac with macOS 13 or older it shows greyed out as “Needs macOS 14” instead of being hidden.
  • A faster default model. On Apple Silicon Macs, the recommended Balanced model now uses the Neural Engine. On an M4 it transcribed about 1.7× faster than the model most of you have been using (large-v3 turbo q5), with the same accuracy (99.5% of words matched the full-size reference, against 99.3% for the old one). It is a bigger download (about 1.6 GB), and Lectern offers it with a banner; nothing changes until you accept.
  • Fastest (Parakeet) — beta. An optional model for Apple Silicon Macs on macOS 14 or newer. On an M4, two real livestream recordings (112 and 326 minutes) ran about 16–18× faster than the old model; the 112-minute one took 19 seconds instead of 5 minutes 23. About 555 MB. Choose it in Settings.
  • Speeds are measured on an M4 Mac. Other chips will differ.
